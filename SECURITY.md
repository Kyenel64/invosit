# Security Policy

Security is the core value proposition of Invosit. If you believe you've found
a vulnerability, please report it privately — **do not open a public issue**.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting:

[**Report a vulnerability**](https://github.com/kyenel64/invosit/security/advisories/new)

## What to include

- A clear description of the vulnerability and the component affected
  (api, cli, frontend, infra)
- Steps to reproduce, including any required configuration
- Impact assessment — what an attacker could do
- Suggested mitigation, if you have one
